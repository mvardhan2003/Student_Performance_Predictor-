# Student Performance Predictor

This project predicts student final grades using machine learning models. It is built using Python and Google Colab Notebook.

## Files

- `Student_Performance_Predictor.ipynb`: Notebook with the full project code.
- `student-mat.csv`: Dataset containing student information and grades of Maths subject.
- `student-por.csv`: Dataset containing student information and grades of Portuguese  subject.


## Technologies Used

- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn

## Steps Performed

1. Load and clean the data
2. Perform data visualization
3. Train machine learning models (Linear Regression, Random Forest, etc.)
4. Evaluate and compare model performance

## How to Run

1. Open the notebook `Student_Performance_Predictor.ipynb`.
2. Make sure `student-mat.csv` is in the same folder.
3. Run all the cells to view results and predictions.
